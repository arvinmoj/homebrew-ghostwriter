# 🍺 homebrew-ghostwriter

Homebrew tap for [GhostWriter](https://github.com/arvinmoj/GhostWriter) — a system-wide AI text refiner.

## Install

```bash
brew tap arvinmoj/ghostwriter
brew install --cask ghostwriter
```

## Update

```bash
brew upgrade --cask ghostwriter
```

## What is GhostWriter?

GhostWriter is a background utility that lets you refine, rewrite, or translate text **anywhere** on your computer — without ever leaving the app you're working in. Highlight text, press a hotkey, and AI-powered instructions transform it on the spot.
